## 📊 API Specification

### Endpoint: POST `/api/tasks/complete-with-claude`

**Request Body**:
```json
{
  "tenantId": "org-uuid",
  "taskId": "task-uuid",
  "taskTitle": "Task Title",
  "taskDescription": "Description...",
  "customPrompt": "Optional additional context",
  "targetStatus": "completed"
}
```

**Success Response (200)**:
```json
{
  "success": true,
  "taskId": "task-uuid",
  "completionNotes": "Generated by Claude...",
  "model": "claude-3-5-sonnet-20241022",
  "tokensUsed": { "input": 150, "output": 85 }
}
```

**Error Response (400-503)**:
```json
{
  "success": false,
  "taskId": "task-uuid",
  "error": "error_code",
  "message": "Human-readable message"
}
```

**Error Codes**:
- `ai_non_configurata` (503) - API key not set
- `ai_chiave_non_valida` (503) - Invalid API key
- `ai_workspace_mancante` (503) - Workspace ID missing
- `limite_richieste_superato` (429) - Rate limit hit
- `prompt_troppo_lungo` (413) - Prompt too long
- `tenant_mancante` (400) - Missing organization ID
- `task_mancante` (400) - Missing task ID

## 🎯 Usage Examples

### Basic Implementation
```tsx
import { CompleteWithClaudeButton } from '@/components/CompleteWithClaudeButton';
import { useAuth } from '@/contexts/AuthContext';

export function TaskCard({ task, onTaskUpdate }) {
  const { organization } = useAuth();

  return (
    <div>
      <h3>{task.title}</h3>
      <CompleteWithClaudeButton
        task={task}
        tenantId={organization.id}
        onComplete={() => onTaskUpdate()}
      />
    </div>
  );
}
```

### Advanced: Custom Hook
```tsx
import { useCompleteTask } from '@/hooks/useCompleteTask';

export function TaskActions({ task, tenantId }) {
  const { completeTask, isLoading, lastError } = useCompleteTask();

  const handleComplete = async () => {
    const result = await completeTask(task, tenantId, {
      customPrompt: 'Include team feedback summary',
      showToast: true,
    });

    if (result.success) {
      console.log('Notes:', result.completionNotes);
    }
  };

  return <button onClick={handleComplete}>{isLoading ? '...' : 'Complete'}</button>;
}
```

### Availability Check
```tsx
import { useAICompletionAvailable } from '@/hooks/useCompleteTask';

export function FeatureGate({ children }) {
  const { isAvailable, isChecking } = useAICompletionAvailable();

  if (isChecking) return <Spinner />;
  if (!isAvailable) return null;
  
  return <>{children}</>;
}
```

## 🐛 Troubleshooting

### Button Not Appearing
**Problem**: "Complete with AI" button not visible  
**Cause**: AI not configured or unavailable  
**Solution**:
1. Check `ANTHROPIC_API_KEY` in Vercel
2. Verify API key is valid
3. Check browser console for errors

### Rate Limit Error
**Problem**: "Completion rate limit reached"  
**Cause**: User hit 30/hour limit  
**Solution**:
1. Retry after 1 hour
2. Increase `AI_COMPLETION_RATE_LIMIT_HOUR` if needed
3. Consider batch operations (Method 2)

### Poor Completion Quality
**Problem**: Generated notes are too generic  
**Cause**: Task description lacks detail  
**Solution**:
1. Use "Complete with Custom Prompt" option
2. Provide specific deliverables context
3. Improve task descriptions in system

See `IMPLEMENTATION_METHOD1.md` for full troubleshooting guide.
